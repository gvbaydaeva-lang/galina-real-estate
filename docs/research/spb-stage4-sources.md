## Что нужно согласовать до публичного показа планировок

Для каждого ЖК необходимо получить либо письменное разрешение на размещение конкретных изображений, либо оригинальные файлы/ссылки, переданные Гиляной для публикации. После этого у соответствующих записей можно заменить `needs-approval` на `approved` и добавить `src`; до этого публичный интерфейс показывает только информацию о подборе и консультации, без копирования изображений.
