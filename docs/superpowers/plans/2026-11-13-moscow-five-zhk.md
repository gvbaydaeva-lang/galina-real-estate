# Пять ЖК Москвы — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Доработать карточки и страницы пяти московских ЖК с подтверждёнными данными, выбором типа квартиры, безопасным калькулятором и локальной проверкой.

**Architecture:** Расширить модель `VerifiedProperty` типизированными квартирными строками и секциями этапов. Вынести общий интерактивный блок пяти новых страниц в отдельный компонент; Ostrov-only JSX и остальные города не трогать.

**Tech Stack:** Next.js/Vinext, React 19, TypeScript, CSS modules/`app/globals.css`, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-13-moscow-five-zhk-design.md`

## Global Constraints

- Изменяются только пять московских ЖК: `moscow-simvol`, `moscow-sobytie`, `moscow-shagal`, `moscow-zilart`, `moscow-level-michurinskiy`.
- «Остров», шесть ЖК Санкт‑Петербурга, шесть ЖК Краснодара, меню, футер и существующие фотографии не изменяются.
- Неподтверждённые цены, площади, планировки, сроки и ставки не добавляются.
- Новые изображения планировок не скачиваются; используются официальные ссылки на подбор.
- Серверная отправка заявок не добавляется и успешная отправка не имитируется.
- Публикация и push не выполняются до отдельного согласования пользователя.

## Review Focus

- Цены и площади не смешиваются между очередями «Левел Мичуринского».
- Shagal не получает выдуманную матрицу цен по комнатности.
- «ЗИЛАРТ» не получает цену или автоподстановку без подтверждённого источника.
- Выбранный тип квартиры реально попадает в DOM формы и меняет начальную цену калькулятора.
- Остальные города и Ostrov-only блок остаются без изменений.

## Files and Responsibilities

- `content/catalog-cities.ts` — типы и подтверждённые данные пяти объектов.
- `components/moscow-property-sections.tsx` — общий интерактивный блок секций для пяти новых страниц.
- `components/property-card.tsx` — универсальные CTA только для пяти новых страниц, Ostrov-поведение сохранить.
- `components/inquiry-form.tsx` — начальное значение выбранного типа квартиры без изменения канала отправки.
- `app/catalog/[city]/[property]/page.tsx` — подключение общего блока только для пяти московских ID.
- `app/globals.css` — стили общего блока и mobile overflow.
- `components/moscow-property-sections.test.tsx`, `components/property-detail-page.test.tsx`, `components/city-catalog.test.tsx`, `components/inquiry-form.test.tsx` — поведенческие и regression-тесты.
