# Contacts Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать страницу «Контакты» по PDF без выдуманных MAX/политики/доставки.

**Architecture:** Страница остаётся статическим маршрутом Next/Vinext. Контент и карточки находятся в `app/contacts`, форма получает отдельный локальный компонент с условными городами, клиентской валидацией и POST-адаптером к заранее настроенному endpoint; отсутствие endpoint обрабатывается как ошибка, не успех.

**Tech Stack:** React 19, Next/Vinext, TypeScript, существующий CSS, Vitest/Testing Library, Playwright/CUA для ручной проверки.

**Spec:** `docs/superpowers/specs/2026-11-11-contacts-page-design.md`

## Global Constraints

- Использовать точные тексты разделов 1–5 PDF.
- Не выдумывать URL MAX, URL политики, адреса и серверные параметры.
- Не менять остальные страницы, меню, подвал, общие стили и нерелевантные интеграции.
- Успешное сообщение разрешено только после подтверждённого ответа сервера.

## Review Focus

- Тема «новостройка» показывает только Москву, Санкт-Петербург и Краснодар; вторичное жильё — только Элисту.
- Ипотека и другой вопрос оставляют город необязательным.
- MAX не становится активной ссылкой без настоящего URL.
- Сетевая ошибка не приводит к сообщению об успехе.
- На ширине смартфона нет горизонтальной прокрутки.
