# Дизайн страницы «Ипотека»

## Цель

Переработать страницу-оглавление ипотечного блога по PDF «Ипотека — этап 1», чтобы она стала понятной точкой входа: помогала выбрать тему, перейти к калькулятору и обратиться за консультацией.

## Границы

- Изменяется только страница `app/mortgage-programs/page.tsx`, которая публикуется как `mortgage-programs.html`.
- Для оформления добавляется отдельный CSS-модуль страницы `app/mortgage-programs/mortgage-index.module.css`.
- `content/mortgage-programs.ts` не изменяется: восемь существующих slug и статьи сохраняются.
- Не изменяются статьи, калькулятор, каталоги, FAQ, контакты, шапка, меню, подвал, глобальные стили и интеграции.

## Структура

1. Intro: надзаголовок, один H1 и описание из PDF.
2. Акцентный материал: «С чего начать? Как выбрать ипотечную программу» со ссылкой на существующую статью `how-to-choose-a-mortgage-program`.
3. Семь компактных карточек в порядке PDF: семейная ипотека, господдержка, IT-ипотека, военная ипотека, ИП и самозанятые, рефинансирование, материнский капитал.
4. Блок калькулятора с ссылкой на существующий маршрут `/mortgage-calculator`.
5. Блок консультации со ссылкой на существующий маршрут `/contacts`.

Все карточки и кнопки будут нативными ссылками через существующий `SiteLink`, поэтому сохранят статические адреса `.html`, клавиатурную доступность и безопасную навигацию проекта.

## Визуальное решение

Локальный CSS-модуль: светлая поверхность, мягкие акцентные оттенки, выразительный intro, широкая выделенная карточка и сетка 3/2/1 колонки. Для ссылок задаются hover/focus-visible состояния, на мобильном — одна колонка, отсутствие горизонтального переполнения и компактные отступы.

## SEO

- Title: `Ипотечные программы и условия покупки жилья | Галина Санджиева`.
- Description: `Семейная, военная и IT-ипотека, господдержка, материнский капитал и рефинансирование. Обзоры программ, ипотечный калькулятор и помощь брокера Галины Санджиевой.`
- Один H1; H2 для тематических материалов, калькулятора и консультации.

## Подходы

- Вариант 1 выбран: разметка страницы и отдельный локальный CSS-модуль. Он лучше всего сохраняет изоляцию и поддерживаемость.
- Вариант 2 отклонён: inline-стили в `page.tsx` усложнили бы адаптивность, фокус и дальнейшее чтение кода.

## Проверка

- `npm run lint`, тесты и `npm run build`.
- Проверка восьми ссылок статей, калькулятора и контактов по собранным `.html`-маршрутам.
- Локальная проверка desktop/mobile в браузере, включая отсутствие горизонтальной прокрутки и обрезанного текста.
- Проверка diff, чтобы убедиться: изменены только страница, её локальный CSS и этот дизайн-док.
- После публикации — проверка GitHub Pages HTML, ссылок, desktop/mobile render и консоли браузера.
