# Дизайн: компактный футер сайта Галины Санджиевой

## Назначение

Заменить общий футер на всех страницах сайта единым компактным блоком в стиле Modern Estate: копирайт слева, официальная подпись Центра «Мой бизнес» Республики Калмыкия и оригинальный логотип справа.

## Цели

- Оставить только `© 2026 Галина Санджиева`.
- Справа показать `Сделано при поддержке Центра «Мой бизнес» Республики Калмыкия` и оригинальный логотип из последней страницы утверждённого ТЗ.
- Сохранить фирменные цвета, компактные отступы и горизонтальную компоновку на широком экране.
- На мобильном экране расположить две группы друг под другом.
- Проверить футер на всех существующих маршрутах и в мобильном viewport до публикации.

## Не входит в задачу

- Изменения шапки, контента страниц, навигации, контактов, изображений объектов и других компонентов.
- Публикация, push или изменение `main` без отдельного разрешения.
- Перерисовка логотипа или замена его текстовой имитацией.

## Подходы

1. Единый `SiteFooter` с локальным asset, извлечённым из 6-й страницы PDF ТЗ. Выбранный вариант: сохраняет оригинальный знак, хорошо контролируется в CSS и не зависит от внешнего URL.
2. Показывать фрагмент PDF как изображение. Не выбран: лишний фон и плохая адаптация.
3. Перерисовать логотип в SVG. Не выбран: нарушает требование использовать оригинальный логотип.

## Реализация

- Обновить только `components/site-footer.tsx`.
- Добавить извлечённый из PDF логотип в `public/images/`.
- Обновить только футерные правила в `app/globals.css`; существующие незакоммиченные изменения сохранить.
- Оставить футер подключённым через общий `app/layout.tsx`, чтобы он отображался на всех страницах.
- Использовать фиксированный текст `© 2026`, без вычисления текущего года.

## Проверка

- Тесты/сборка проекта и `git diff --check`.
- Проверка, что старые навигационные ссылки и дополнительные блоки футера исчезли.
- Визуальный просмотр главной, внутренних, каталожных, ипотечных и 404-маршрутов на desktop и mobile viewport.
- Проверка, что изменены только футер и добавленный оригинальный asset.
