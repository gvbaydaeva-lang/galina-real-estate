# Возврат к месту перехода — дизайн

## Цель

Стрелка на странице конкретного ЖК возвращает посетителя к той же карточке
на странице города, из которой он открыл ЖК, а не в начало каталога.

## Границы

- Меняется только путь перехода между карточкой ЖК и страницей этого ЖК.
- Названия, изображения, фильтр, оформление стрелки и другие разделы сайта не меняются.

## Решение

У каждой карточки будет стабильная невидимая метка `property-<id>`. Ссылка
на страницу ЖК передаст в адрес возврата метку карточки и выбранный район.
Страница ЖК прочитает только безопасные параметры своего адреса и передаст
полученный адрес стрелке. Каталог восстановит выбранный район из адреса,
после чего браузер перейдёт к карточке по метке.

## Поведение

- Карточка «Остров» из общего каталога Москвы возвращает на `/catalog/moscow#property-moscow-ostrov`.
- При выбранном районе URL дополнительно хранит этот район; после возврата в
  фильтре остаётся тот же выбор.
- Если страницу ЖК открыли напрямую, стрелка по-прежнему ведёт в каталог
  города без специальной позиции.
- Внешние и произвольные адреса не принимаются как адрес возврата.
