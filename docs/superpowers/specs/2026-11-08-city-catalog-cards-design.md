# Карточки ЖК в каталогах городов

## Цель

Наполнить каталоги Москвы, Санкт-Петербурга и Краснодара шестью проверенными карточками ЖК в каждом. Каталог должен помогать сориентироваться по городу, но не публиковать цены, условия, фотографии, контакты или имя застройщика.

## Решение

Карточка показывает только название ЖК, район или локацию, нейтральный тип проекта и дату проверки. Официальный URL хранится в отдельном служебном реестре источников для последующей проверки; он не передаётся в браузер, не выводится в HTML и не становится ссылкой. Посетитель остаётся на сайте. На странице также будет честная пометка, что подборка не исчерпывающая, а способы связи ещё готовятся к публикации.

## Данные и границы

- По шесть карточек: Москва, Санкт-Петербург и Краснодар; Элиста остаётся без объектов.
- Отбор основан на наличии актуальной официальной страницы, а не на непроверяемом обещании продаж.
- Не показывать имя застройщика, цены, акции, сроки, изображения, ипотечные условия, внешние ссылки, форму или контакты.
- Районный фильтр должен содержать только локации, в которых есть опубликованные карточки.
- Дата проверки для всех карточек: 2026-11-08.

## Рассмотренные варианты

1. Вести карточки на внешние страницы источников. Отказано: это уводит посетителя с сайта и противоречит цели каталога.
2. Добавить внутренние страницы каждого ЖК. Отложено: для них понадобится отдельно согласовать объём текста, SEO и регулярное обновление данных.
3. Оставить карточки внутри каталога с минимально необходимыми фактами и внутренним источником для аудита. Выбрано: это безопасно, честно и не создаёт неподтверждённых обещаний.

## Успех

На трёх страницах каталога видны по шесть аккуратных карточек; фильтр работает; Элиста честно показывает пустое состояние; нет видимых внешних ссылок, данных застройщиков, цен или контактов.
