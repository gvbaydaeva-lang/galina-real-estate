# Изображения для карточек ЖК — краткий дизайн

## Цель

Сделать карточки ЖК в каталогах визуально понятнее, добавив только изображения, найденные на официальных страницах соответствующих проектов.

## Подходы

1. Скачать фотографии в репозиторий. Не выбран: это копирование чужих материалов без отдельного подтверждения прав.
2. Сгенерировать изображения. Не выбран: это не фотографии реальных ЖК.
3. Загружать подтверждённые изображения напрямую с официальных страниц. Выбран: сайт не копирует файлы, а показывает исходные публичные изображения.

## Решение

- В данных ЖК добавить `image` только если официальный источник страницы отдаёт конкретное изображение проекта.
- В интерфейсе не показывать названия застройщиков и не добавлять ссылки на их сайты.
- Для карточек без надёжно сопоставленного изображения показать аккуратный нейтральный блок «Фото проекта уточняется» вместо случайной фотографии или пустого пространства.
- Указать содержательный `alt` с названием ЖК; не добавлять цены, условия, контакты и новые обещания.
- Сохранить адаптивную сетку: две карточки на широком экране и одну на мобильном.

## Границы

Это не добавляет отдельные страницы ЖК, форму заявки, передачу данных или сторонние интеграции. Внешние изображения могут стать недоступны на стороне их владельца; в таком случае карточка сохраняет текстовую информацию.
