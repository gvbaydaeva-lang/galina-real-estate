# Страница «Контакты» — дизайн

## Цель

Заменить временную страницу контактов точным содержимым из PDF: пять блоков в заданном порядке, подтверждённые каналы связи, адаптивная форма заявки и SEO-метаданные.

## Границы

- Изменяются только `app/contacts/page.tsx`, локальные стили/компоненты формы, связанные тесты и план/спецификация.
- Общая шапка, подвал, другие страницы и существующие интеграции не меняются.
- В форму передаются только поля из PDF; адреса офисов, MAX URL и политика не выдумываются.

## Подходы

1. Подключить отправку сразу через новый backend: не подходит без проверенного endpoint, URL политики, Telegram bot token и chat ID.
2. Оставить старую браузерную заглушку: не подходит, потому что PDF требует полноценную форму и запрещает ложное состояние успеха.
3. Рекомендуемый и согласованный подход: внедрить готовую страницу, полную клиентскую валидацию и безопасный адаптер отправки, который обращается только к настроенному серверному endpoint; при его отсутствии показывает ошибку и предлагает мессенджеры. MAX остаётся неактивным до получения настоящего URL. Согласие ссылается только на реально существующую опубликованную политику; если её нет, форма не публикуется как рабочая до получения адреса.

## Ожидаемый результат

Первый экран → способы связи → форма → география → заключение. Telegram, WhatsApp и телефон используют URL из PDF; MAX показывает номер для поиска. Города зависят от темы обращения. Успех показывается только после подтверждённого ответа сервера, а сетевой сбой показывает ошибку.

## Что остаётся для финального запуска

Настоящая ссылка MAX, URL политики обработки персональных данных и серверный endpoint с защищёнными секретами Telegram. До этого в отчёте явно указывается, что доставка заявок не подтверждена.
