# Расширенные тексты страниц ЖК

## Задача

Сделать страницы отдельных жилых комплексов более содержательными и привлекательными для человека, который уже открыл конкретный ЖК.

## Границы

- Меняется только контент, который показывается после открытия отдельной страницы ЖК.
- Карточки в городских каталогах сохраняют нынешний компактный объём.
- Во всём опубликованном тексте каталога не используется слово «застройщик».
- Описания остаются нейтральными: используются только уже подтверждённые особенности проекта, без цен, сроков, гарантий или новых неподтверждённых характеристик.

## Подходы

1. Расширить существующие короткие описания: не подходит, потому что тем же длинным текстом будут перегружены карточки каталога.
2. Добавить отдельные `detailDescription` и `detailHighlights` для страниц ЖК: выбранный вариант. Он увеличивает объём после клика, не меняя превью в каталогах.

## Результат

Для каждого из 18 опубликованных ЖК на отдельной странице выводятся четыре абзаца: характер локации, сценарий повседневной жизни, территория и инфраструктура, важный ориентир при выборе корпуса. Рядом отображается блок из пяти ключевых особенностей.
