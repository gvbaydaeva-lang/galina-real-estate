# Подтверждённые карточки ЖК: Москва, Санкт-Петербург и Краснодар

## Цель

Наполнить три городских каталога небольшим срезом новостроек, который можно проверить без агрегаторов: у каждой карточки есть название ЖК, застройщик, район, класс, ориентировочная цена и прямая официальная страница проекта. Элиста остаётся без карточек с честным сообщением «Данные уточняются».

## Границы

- Для Москвы, Санкт-Петербурга и Краснодара — по 5 карточек, у нескольких застройщиков.
- Цена записывается в формате «от … ₽» и относится только к дате проверки 05.11.2026.
- Не добавляются изображения, тексты застройщиков, агрегаторы, формы, база данных или автоматическое обновление цен.
- Районный фильтр показывает только карточки выбранной локации; список локаций дополняется только теми, которые нужны этим карточкам.
- Под списком показывается: «Это не полный список предложений: есть и другие варианты. Для подбора по району, бюджету и срокам обратитесь за консультацией.»

## Данные и проверка источников

Карточка публикуется лишь если официальная страница застройщика содержит название проекта, город и цену. Для каждой карточки сохраняются URL и дата проверки. Класс жилья берётся с той же официальной страницы; если проект объединяет классы, это отражается без упрощения.

## Интерфейс

Карточка показывает только текстовые сведения: район, класс жилья, название ЖК, застройщика, цену, дату проверки и внешнюю ссылку «Официальный источник». Для безопасности внешняя ссылка открывается в новой вкладке с `rel="noreferrer"`. Без изображений сетка остаётся компактной и читаемой на мобильном экране.

## Риски

Цены и доступность меняются у застройщиков, поэтому это ориентир, а не оферта. Перед следующей публикацией или рекламной кампанией ссылки и цены нужно сверить заново.
