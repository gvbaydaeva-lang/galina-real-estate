# Стрелочная навигация возврата

## Задача

Сделать на внутренних страницах сайта одну компактную стрелку возврата над заголовком без видимого текста.

## Логика переходов

- Страница конкретного ЖК возвращает в каталог своего города.
- Каталог города возвращает к выбору городов на главной странице.
- Статья об ипотеке возвращает к списку материалов об ипотеке.
- Самостоятельные разделы (услуги, FAQ, контакты, калькулятор, список ипотечных материалов и 404) возвращают на главную страницу.
- Главная страница стрелку не показывает.

## Ограничения

- Стрелка ведёт на фиксированный родительский маршрут, а не использует историю браузера.
- На экране виден только символ «←»; понятное имя ссылки остаётся только для программ чтения с экрана.
- Нижняя текстовая ссылка возврата на странице ЖК удаляется, чтобы не дублировать навигацию.
